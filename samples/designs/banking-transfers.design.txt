DESIGN-001: Users will authenticate using a username and password; MFA setup will be mandated for all users.

DESIGN-002: The transfer API will target a response time of 2.5 seconds for 95% of requests under 1,000 concurrent users.

DESIGN-003: The transfer API will retry failed transfer operations automatically without an idempotency mechanism.

DESIGN-004: The system will debit the source account and credit the destination account using two independent database transactions.

DESIGN-005: The system will replicate transaction data to a secondary region every 5 minutes and target recovery within 60 minutes.

DESIGN-006: Transaction audit records will be retained for 10 years in a standard database table, with update and delete permissions granted to application administrators.

DESIGN-007: All external API traffic will use HTTPS; internal service-to-service communication will use HTTP within the private network.
